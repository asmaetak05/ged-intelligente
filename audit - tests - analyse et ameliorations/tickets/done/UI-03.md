# 🎫 UI-03 — Skeletons de chargement pour les KPIs et Graphiques

## Détails de réalisation
- Création d'un composant de base réutilisable `Skeleton.jsx` utilisant la classe Tailwind `animate-pulse` pour un rendu de type "chargement clignotant".
- Refactoring complet du composant `Dashboard.jsx` :
  - Remplacement de l'appel direct à `axios` par le client API centralisé `apiClient` créé à l'étape précédente.
  - Ajout d'états locaux `loadingKpis` et `loadingCharts` initialisés à `true`.
  - Modification du rendu conditionnel : tant que les appels API ne sont pas terminés (dans la clause `.finally()`), l'interface affiche les composants `<Skeleton />` au lieu du contenu final.
  - Les skeletons ont été adaptés au design des widgets KPIs (blocs de texte factices) et des conteneurs de graphiques (bloc complet) pour éviter tout saut de mise en page lors du chargement.
