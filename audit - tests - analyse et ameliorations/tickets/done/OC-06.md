# Réalisation OC-06

**Ticket** : OCR bilingue FR/AR par page
**Statut** : Terminé

**Détails de l'implémentation** :
- Configuration de l'argument `lang='fra+ara'` pour `pytesseract` dans `ocr/extract_ocr.py`.
- L'extraction peut désormais récupérer conjointement des mots en français et en arabe sans corrompre le texte arabe en symboles incompréhensibles.
- Ajout d'une logique de repli (fallback): si l'appel avec les deux langues échoue (ex. modèle manquant), l'extracteur se rabat sur le français, puis sur le modèle par défaut.
