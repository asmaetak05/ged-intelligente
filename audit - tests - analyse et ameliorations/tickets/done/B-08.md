# Rapport d'implémentation : Ticket B-08 (CORS & Sécurité HTTP)

## 📋 Informations
- **Lot** : Lot 1 (Authentification & Sécurité)
- **Ticket** : B-08
- **Statut** : Terminé ✅

## 🛠️ Réalisations techniques
1. **Durcissement CORS** :
   - `backend/main.py` : la liste des origines autorisées (CORS) est désormais pilotable par la variable d'environnement `ALLOWED_ORIGINS` et s'applique globalement à l'API.
2. **En-têtes de Sécurité HTTP** :
   - Création d'un middleware HTTP asynchrone (`@app.middleware("http")`) dédié à l'injection d'en-têtes de sécurité.
   - Ajout systématique de `X-Content-Type-Options: nosniff`.
   - Ajout systématique de `X-Frame-Options: DENY` (contre le clickjacking).
   - Ajout de `Strict-Transport-Security: max-age=31536000; includeSubDomains` (HSTS).

## 🧪 Validation
- Le test unitaire `test_security_headers` valide la présence correcte et la valeur attendue pour chacun de ces trois en-têtes HTTP de sécurité.
