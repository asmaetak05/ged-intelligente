# 🎫 UI-02 — Intercepteur Axios + Notifications Toast (Sonner)

## Détails de réalisation
- La bibliothèque **Sonner** a été installée (`npm install sonner`) pour gérer les notifications toast non bloquantes.
- Le fichier `src/api/axios.js` a été créé. Il configure une instance Axios centralisée.
- Un **intercepteur de réponses HTTP** a été ajouté pour capturer globalement les erreurs :
  - **Erreurs 4xx / 5xx** : Sont détectées et affichent un toast d'erreur rouge avec le code statut et le message d'erreur provenant de l'API.
  - **Erreurs réseau** : Si aucune réponse n'est reçue du serveur, un message d'erreur spécifique est affiché à l'utilisateur.
- Le composant global `<Toaster richColors position="bottom-right" />` a été ajouté à la racine de l'application dans le composant `App.jsx`, garantissant que les notifications peuvent s'afficher par-dessus toutes les vues.

**Statut : Terminé ✅**
