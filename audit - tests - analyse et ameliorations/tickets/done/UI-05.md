# 🎫 UI-05 — Panneau de filtres avancés

## Détails de réalisation
- Création du composant `AdvancedFilters.jsx` qui sert de panneau pour les critères avancés.
- Intégration d'un bouton de type "toggle" (Filtres) à côté de la barre de recherche dans `SearchFTS.jsx` permettant d'ouvrir et fermer le panneau (`isOpen`).
- Le panneau comprend les champs de filtrage suivants, modifiant tous un objet de state centralisé `filters` :
  - **Type de procédure** (Ouvert, Restreint)
  - **Statut de l'avis**
  - **Date d'ouverture des plis**
  - **Qualifications requises**
  - **Caution provisoire min/max** (MAD)
- Modification de la fonction de récupération des données `fetchResults` dans `SearchFTS.jsx` pour inclure dynamiquement ces filtres sous forme de paramètres de requête (`URLSearchParams`) vers l'API.

**Statut : Terminé ✅**
