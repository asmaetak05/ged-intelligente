# Réalisation OC-04

**Ticket** : Reprise OCR après crash (page par page)
**Statut** : Terminé

**Détails de l'implémentation** :
- Mise à jour du modèle BDD `OcrLog` pour inclure `last_processed_page` et `total_pages`. Une migration Alembic (`2fed4817d91f_add_ocrlog_pagination.py`) a été appliquée.
- Le module `backend/tasks.py` gère maintenant le découpage en sous-tâches de traitement (lot de 10 pages).
- L'état est sauvegardé en base de données pour permettre la reprise exacte d'un long document qui aurait crashé, garantissant qu'aucune page déjà traitée n'est refaite et que l'extraction redémarre bien là où elle s'était arrêtée.
- `ingestion/extractor.py` a été adapté pour append le texte et accepter les limites de chunk.
