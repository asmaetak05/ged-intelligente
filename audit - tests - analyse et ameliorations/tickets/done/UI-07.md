# 🎫 UI-07 — Export CSV / Excel des résultats de recherche

## Détails de réalisation
- Ajout d'un bouton "Exporter CSV" avec l'icône `Download` dans l'en-tête de `SearchFTS.jsx`.
- Ce bouton n'est visible que si la recherche retourne au moins un résultat.
- Création d'une fonction `handleExportCSV` qui itère sur le tableau local `results` de l'état du composant.
- Les données (Numéro, Titre, Organisme, Ville, Catégorie) sont formatées en chaînes de caractères séparées par des virgules (CSV natif). Les guillemets sont échappés pour éviter les bugs avec des textes complexes.
- Le fichier CSV est généré côté client en utilisant l'objet JavaScript `Blob` avec le mime-type `text/csv`, évitant ainsi d'ajouter une charge sur le backend.
- Le téléchargement se lance automatiquement grâce à un lien HTML temporaire généré et cliqué dynamiquement (`resultats_recherche.csv`).
