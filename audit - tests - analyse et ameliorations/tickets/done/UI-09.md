# 🎫 UI-09 — Filtrage des résultats par état de l'avis (En cours, Clôturé)

## Détails de réalisation
- Intégré dans le nouveau composant `AdvancedFilters.jsx`.
- Ajout d'un menu déroulant (`<select>`) avec l'attribut `name="statutAvis"` proposant les états :
  - Avis en cours
  - Résultats publiés
  - Annulé
  - Clôturé
- Le statut sélectionné par l'utilisateur est conservé dans le store local `filters` et est automatiquement attaché à la querystring sous le paramètre `statut_avis` lors de l'appel à la fonction `fetchResults`.
