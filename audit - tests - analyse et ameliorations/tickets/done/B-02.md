# Rapport d'implémentation : Ticket B-02 (RBAC)

## 📋 Informations
- **Lot** : Lot 1 (Authentification & Sécurité)
- **Ticket** : B-02
- **Statut** : Terminé ✅

## 🛠️ Réalisations techniques
1. **Modélisation (`backend/models.py`)** :
   - Ajout de l'énumération `UserRole` (`reader`, `analyst`, `admin`).
   - Création de la table `users` pour stocker les informations de compte (Alembic migration générée avec succès).
2. **Dépendances FastAPI (`backend/auth/rbac.py`)** :
   - Création de la dépendance `get_current_user` qui lit et vérifie la validité du Bearer Token.
   - Création de la dépendance de classe `RequireRole(allowed_roles=[...])` pour sécuriser les routes de manière granulaire. L'administrateur a implicitement un accès global.
3. **Application pratique** :
   - La route `POST /api/v1/ged/documents/upload` est désormais protégée et requiert a minima le rôle `analyst` (ou `admin`).
   - Le WebSocket `/api/v1/system/ws/console` est protégé par l'extraction du token depuis les requêtes et restreint à `admin`.

## 🧪 Validation
- Couverture fonctionnelle par les tests dans `tests/test_auth.py` (vérification de l'erreur 403 HTTP Forbidden pour un accès non autorisé).
