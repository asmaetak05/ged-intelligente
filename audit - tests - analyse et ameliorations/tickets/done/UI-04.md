# 🎫 UI-04 — Bouton « Réinitialiser » sur les filtres de recherche

## Détails de réalisation
- Ajout d'une fonction `handleReset` dans le composant `SearchFTS.jsx`.
- Cette fonction réinitialise à la fois les mots-clés de la barre de recherche (`query`) et tous les filtres actifs de l'objet `filters` en les passant à vide.
- Elle vide également les résultats de recherche actuels et réinitialise la pagination (`page` à 1, `total` à 0).
- Le bouton a été intégré directement dans l'entête du panneau `AdvancedFilters.jsx` avec l'étiquette "Réinitialiser".
