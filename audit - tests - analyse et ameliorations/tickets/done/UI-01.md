# 🎫 UI-01 — Gestion d'état globale avec Zustand

## Détails de réalisation
- **Zustand** a été installé dans le projet (`npm install zustand`).
- Le dossier `src/store` a été créé.
- Le store `useUIStore.js` a été implémenté pour gérer l'état global de l'interface utilisateur (ouverture/fermeture du menu latéral, mode sombre, cache des KPIs).
- Le store `useAuthStore.js` a également été mis en place de manière préventive pour gérer l'authentification (utilisateur, token, état d'authentification).
- Ces stores pourront être importés dans les composants via `import useUIStore from '../store/useUIStore';` et utilisés pour remplacer les props ou des états locaux redondants.

**Statut : Terminé ✅**
